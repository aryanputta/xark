The timed service interval starts before reading each request and ends when
the public `PreparedCpuProver::prove` API or equivalent upstream CPU path
returns. It includes solving, row checks, proof construction, Xark positive
self-check, and proof/public serialization. Each warmup and measured proof is
then independently checked with Xark and Arkworks against the correct, altered,
and cross-request statements outside the timed interval. Peak RSS is the
maximum child-process `wait4().ru_maxrss` across measured blocks.

## Isolated cleanup cost

The separate [three-arm ablation run](https://github.com/aryanputta/xark/actions/runs/46124920790)
at benchmark commit `c7b9bc33fabd8db77966d22a3605833e9d70b025` passed six
same-binary control pairs and measured 120 verified requests per arm/circuit
in six balanced 20-request blocks. The [raw receipt artifact](https://github.com/aryanputta/xark/actions/runs/46124920790/artifacts/15254904867)
has ZIP SHA-256 `2a33ab0fb7c79287e5187b0f12822d4aff1bd193a7e3a56e4f3130bb3195e9fe`.
All three arms used the identical public API caller (SHA-256
`a039fe7c9f80801fc4da0c9856dfb10aa5d5477ad9aa5813361cc0e6d48b4108`).

| Circuit | Before cleanup `2b7190ab` p50/p95 | After two cleanup commits `98ef6858` p50/p95 | Final guarded `5cadc60e` p50/p95 |
| --- | ---: | ---: | ---: |
| Escrow | 110.548 / 112.383 ms | 110.053 / 113.139 ms | 109.603 / 112.805 ms |
| Withdrawal | 86.921 / 88.543 ms | 87.588 / 89.377 ms | 86.642 / 89.027 ms |

The isolated two-commit p50 difference was −0.496 ms for escrow and +0.667 ms
for withdrawal; preparation changed +3.775 ms and +1.604 ms, respectively.
The later guarded-head p50 difference from the after-cleanup arm was −0.450 ms
for escrow and −0.946 ms for withdrawal. All six control pairs passed 2% p50
and 10% p95 drift gates, but observed control drift reached 1.456% at p50 and
6.836% at p95, larger than these sub-millisecond differences. This run does
not resolve a small cleanup cost in either direction. Absolute service times
from this ablation and the separate upstream comparison are not paired and
must not be compared.

The GitHub Actions artifacts contain the raw stdout/stderr per invocation,
topology, binary/source hashes, complete receipt counts, and report JSON.
The artifacts are currently retained by GitHub for 90 days. Local artifact ZIP
download was blocked by DNS in the reviewing environment, so the raw samples
were not independently reparsed here. The runner itself parses and checks the
complete receipt sequence before reporting eligibility.

The [receipt transfer workflow](../../.github/workflows/pr106-publish-receipts.yml)
downloads all three public artifacts on GitHub's hosted runner, screens the
files for credential-like strings, reparses every raw service receipt against
the JSON report and reported percentiles, then commits the extracted files
under [evidence/raw](evidence/raw) on this evidence branch. Its run must pass
before treating that path as an independently audited raw receipt copy.
