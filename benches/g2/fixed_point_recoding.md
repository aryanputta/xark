# Exact fixed-point digit alphabets for BN254 G2

This reference checks full digit coverage in two small quotient rings using Python integers. The constructions are for public test vectors. Digit selection and bucket addressing are data dependent.

## Fan, Kuchta, Sica and Xu integer correction

Use radix $q=2048$ and signed multipliers $\pm1,\pm2,\pm3$. Section 3 starts with $1\le b\le q/2$ of even 3-adic valuation. Remove elements of odd 2-adic valuation and elements of the form $q-3j$ where $j<q/4$ is odd and belongs to the starting set. Include zero for encoding an empty contribution. At this radix the exact result has 448 buckets including zero, maximum sorted gap six, and covers all 2,048 residue classes. [Fan, Kuchta, Sica and Xu, ePrint 2024/750 §3](https://eprint.iacr.org/2024/750)

For each residue, the reference chooses a covered product of smallest absolute value. Applying 24 divisions gives an exact signed-digit expansion plus a top residual. Since $|mb|\le3q/2$, the residual bound is $r/q^{24}+(3/2)q/(q-1)<2$ for canonical BN254 scalars. Reserve one additional $q^{24}$ point per base and apply the residual sign. The resident point count is $73n$. At 128 bytes per affine G2 point that is 67.78 MiB for escrow and 48.17 MiB for withdrawal.

## Le and Sica six-unit model at $c=5$

Work in $\mathbb Z[\omega]$, with $\omega^2+\omega+1=0$ and squared norm $N(a+b\omega)=a^2-ab+b^2$. On BN254 G2 the map $\phi=-\psi^2$ has eigenvalue $-\lambda^2\bmod r$. For the BN seed $u$, the principal kernel generator
$$
\alpha=(6u^2+4u+1)+(2u+1)\omega
$$
evaluates to zero under this eigenvalue and has $N(\alpha)=r$. The evaluation is onto because constants already cover all residues. The ideal generated by $\alpha$ therefore equals the kernel by its index. Lift $s$ by subtracting $\alpha$ times the componentwise nearest integer to $s/\alpha$. This gives $|\kappa_0|\le\sqrt{3r/4}$. The lift requires validated G2 subgroup points when used as a group action. [BN254 G2 twist Frobenius and scalar action](bn254_twist_frobenius.md)

Take $q=(2-\omega)^5=-87-149\omega$, of norm 16,807. For a candidate digit $z$, calculate $x+y\omega=z\bar q$. The closed Voronoi hexagon is given by
$$
\max(|2x-y|,|2y-x|,|x+y|)\le N(q).
$$
These are the six perpendicular bisectors for the nearest neighbors of the triangular lattice. Its radius is $|q|/\sqrt{3}$. Enumerate lattice points in this hexagon and the sector $a>b\ge0$ for $z=a+b\omega$, using one representative per unit orbit. Label each residue by $(62a-149b)\bmod 16807$. This map vanishes on $q\mathbb Z[\omega]$ and is onto because 62 is coprime to 16,807. Its kernel has the same index as the radix ideal, so these labels identify the classes exactly. The reference recovers all 16,807 labels with 2,802 buckets including zero. The nonzero counts by $(2-\omega)$-valuation are 2,401, 343, 49, 7, and 1. This is an independent closed-region enumeration of the six-unit covering. [Le and Sica, ePrint 2026/1902 Theorem 1](https://opencryptology.org/2026/1902.pdf)

If a residual $\kappa_j$ selects the unit-applied digit $d_j$, subtract it and divide exactly by $q$. The next residual obeys $|\kappa_{j+1}|\le (|\kappa_j|+|d_j|)/|q|$. At every step $|d_j|/|q|\le1/\sqrt3<3/5$. Since $|q|>128$ and $8100r<N(q)^{19}$, the 19-step tail has
$$
|\kappa_{19}|<1/90+(3/5)(128/127)<1.
$$
The only Eisenstein integer in this range is zero. This gives an all-scalar zero-tail guarantee alongside the deterministic boundary and random checks.

The table counts 19 affine entries per point including the original and 18 successive radix maps. One radix map can use a joint binary schedule for $[-87]P+[-149]\phi(P)$ with seven doubles, one subset addition, and five accumulator additions. Computing $\phi(P)$ is two base-field multiplications. A straightforward table builder would repeat that schedule for each successive entry before batch normalization. A nonzero digit requires an indexed table read, one optional sign, at most one sparse cubic map for a unit power using a prederived field constant, and one bucket accumulation.

The 2,801 nonzero buckets imply 537,792 bytes of projective coordinate payload at 192 bytes each. A dense 16-bit residue table would consume 33,614 bytes for a 12-bit bucket ID and a three-bit unit ID. These counts exclude coordinates for queue or scratch state, alignment, the rest of the key, and process RSS. Le and Sica's short-edge Hamiltonian path supplies a further reduction cost of roughly 2,801 suffix steps and short difference actions. This reference has verified coverage and recoding. That path and real-fixture performance remain open. [Le and Sica, Theorem 2 and Table 1](https://opencryptology.org/2026/1902.pdf)

### Normalized nonzero bucket submissions

The archived Xark occupancy counter named `adds` increments once for each nonzero Booth digit submitted to the affine bucket path. It includes first writes to an empty bucket and excludes later bucket reduction. On the same high-width GLV class, charge the hexagonal recoder a full 19 submissions per original base even if some digits are zero. Its submission bound then falls by at least 20.67% for escrow and 20.69% for withdrawal within that class.
